#  Fundamental Booster & Personal Data Collector

**Author:** Jenisha Ramani
**Course/Project:** Python Practical Assignment

A Python console application designed to collect user details, display data types and memory addresses, and calculate birth years based on input age.

## 🚀 Features

* **Interactive Data Collection:** Prompts the user to input their name, age, height, and favorite number.
* **Type & Memory Tracking:** Displays the data type (`str`, `int`, `float`) and memory address of each variable.
* **Age Calculation:** Estimates the approximate birth year dynamically.


## 🎯 Purpose

This project is created to practice **Python fundamentals**, including user input, variables, data types, type conversion, memory addresses, and basic calculations.
